How detection works

  • Uses Bungie endpoints only: player search, linked profiles, character activity history, post-game carnage reports, and manifest definitions.
  • Solo flawless full clears require Bungie's activityWasStartedFromBeginning flag when available; low-man raid clears are shown for any completed PGCR.
  • Team size is counted from unique Destiny memberships in each raid/dungeon PGCR.
  • Flawless means every PGCR entry has zero deaths. Solo flawless additionally requires team size 1.
  • Contest clear detection checks a built-in list of contest raid/dungeon activity hashes and launch-window dates, so older contest clears can be found without fetching PGCRs for every historical clear first.
